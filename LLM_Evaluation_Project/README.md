LLM Evaluation Using QA Framework
This project evaluates ChatGPT's performance using a structured Quality Assurance (QA) testing methodology.
The goal is to assess the model’s ability to consistently, accurately, and safely answer technical and logical prompts.
This project includes:
A set of 25 QA-focused prompts
A detailed evaluation matrix measuring 6 criteria
A final analysis report (PDF)
A scoring sheet (Excel)
Key insights on LLM strengths and limitations

The project demonstrates practical experience in:
LLM Evaluation
Prompt Engineering
AI Behavior Analysis
Test Design & Scoring Logic
Analytical Documentation
